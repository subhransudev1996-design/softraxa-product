After Phase 1: Feature Expansion Roadmap
Phase 2 — Better Billing & Business Documents

Add these after your first billing/inventory version becomes stable.

1. Estimate / Quotation

Very important for hardware shops and mobile shops.

Features:

Create estimate
Convert estimate to invoice
Estimate expiry date
Customer approval status
PDF/share option

Example:
A hardware shop gives a quotation for paint, pipes, cement, and tools before final billing.

Vyapar supports estimates/quotations and conversion-style transaction workflows, so this is a good benchmark feature.

2. Proforma Invoice

Useful for B2B customers.

Features:

Create proforma invoice
Convert proforma to sale invoice
Show GST/tax estimate
Add delivery terms

This is useful when the sale is not final yet but the customer wants a formal price document.

3. Sales Order

Useful when customer orders today but delivery happens later.

Features:

Create sales order
Reserve stock
Partial delivery
Convert to invoice
Track pending orders

Vyapar has partial sales order workflows where stock can be reserved and partial invoices can be generated.

4. Purchase Order

Useful for ordering products from suppliers.

Features:

Create purchase order
Send order to supplier
Convert purchase order to purchase bill
Track ordered vs received quantity

Very useful for hardware and mobile shops.

5. Delivery Challan

Useful when goods are sent without immediate billing.

Features:

Create delivery challan
Convert challan to invoice
Track returned goods
Print challan

Vyapar supports delivery challan-related workflows, so this is also a strong feature to add after V1.
